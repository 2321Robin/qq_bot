# Data, Image, and Derivative Work Licensing

This file documents the origin, licensing status, and redistribution
conclusion for every content category found in this repository.

## Legal notice

The MIT license in `LICENSE` covers only the project's original code
and documentation. **It does not grant rights** to third-party data,
images, icons, trademarks, or game content described below.

## Content categories

### 1. BWiki page text and raw templates

| Field | Value |
|---|---|
| Source | https://wiki.biligame.com/rocom/ |
| Origin | User-contributed wiki content hosted by Bilibili Wiki |
| License claim on source pages | [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) |
| Attribution required | Yes (per CC BY-NC-SA 4.0) |
| Commercial use allowed | No (per NC clause) |
| How we obtain it | Offline fetch script (`scripts/fetch_roco_pet_detail.py`) reads raw wiki templates. The bot does **not** fetch wiki pages at runtime. |
| **Redistribution conclusion** | **Uncertain.** BWiki pages carry a CC BY-NC-SA notice, but we cannot verify that every contributor agreed to this license or that the wiki platform has the right to sublicense. |
| **Decision for public repository** | **Excluded.** `data/roco_pet_details/` is kept private. The public repository contains only code and small test fixtures with no wiki-derived data. |

## Notes

- The public repository distributes **only** the code, documentation, and
  test fixtures described in sections 4 and 5 above. Data directories
  (`data/roco_pet_details/`, `data/roco_assets/`, `data/roco_pet_cards/`)
  are not included in the public tree or public git history.
- Git LFS changes storage, not licensing. Excluding these directories
  from the public repository is a licensing decision, not a storage one.
